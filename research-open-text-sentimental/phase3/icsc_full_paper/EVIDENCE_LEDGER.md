## Manuscript rules

1. The **0.792 fresh-test score** belongs to the model trained on the **2,080-post historical revised-development set**. Never attribute it to a model fitted on 2,166 audited posts.
2. Treat the 2,166-post audit as subsequent label-quality sensitivity evidence. Any evaluation of a refitted model on the already viewed test sets is post hoc.
3. The classifier was given the human-established software/update scope. It is not an end-to-end automatic discovery system.
4. Diagnostic fields mean observable information in saved title/body. No developer-usefulness or resolution outcome was measured.
5. Release a separate, versioned final counts table when writing; if a number changes, update this ledger before the manuscript.
6. Cite the **revised v2** 2,080-post development population for the historical fresh-test model. `phase3/experiment_v1/RESULTS.md` describes an earlier 2,084-post snapshot and is not the training-population reference for the later fresh test.
7. The 200-post packet was completed as **reported separate first passes**, per Manu's clarification. State that process provenance explicitly. Report 100% observed agreement and kappa 1.0 on eligible fields without calling the labels objectively correct or generalizing perfect agreement to future samples. Earlier corpus exposure may remain.
8. The semantic comparator is **development-only**. It uses inner-fold thresholds, whereas the audited fixed-configuration sensitivity uses the historical 0.5877 threshold. Its 0.8385 TF-IDF row is therefore not a contradictory reproduction of the 0.8431 fixed-threshold row. Neither row is a new test result.
